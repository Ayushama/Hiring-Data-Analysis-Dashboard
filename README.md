# 📊 Hiring Data Analysis Dashboard

This project is all about making sense of hiring data through a simple, interactive **Power BI dashboard**.  
The dataset covers employee hiring activities from 2014, and the dashboard was built to uncover trends, bottlenecks, and key insights that can help HR teams make smarter decisions.

---

## 🌟 Why I Built This
Hiring is one of the most important (and often challenging) parts of running a business.  
With this project, I wanted to explore how data can answer questions like:
- Are we hiring consistently across the year, or are there seasonal spikes?  
- How long does it usually take to fill a position?  
- Where in the hiring funnel are we losing the most candidates?  
- Which departments are hiring the most (or struggling the most)?  

By building this dashboard, I was able to practice **data cleaning, visualization, and storytelling**—skills that are crucial for any data analyst role.

## 📈 What the Dashboard Shows
- **Hiring Trends** → Monthly and quarterly recruitment patterns.  
- **Time-to-Fill** → Average days needed to close open roles.  
- **Hiring Funnel** → Applications → Shortlisted → Interviews → Offers → Hires.  
- **KPIs** → Quick snapshot of overall hiring performance.  
- **Department View** → Which teams are hiring the most, and where challenges exist.
